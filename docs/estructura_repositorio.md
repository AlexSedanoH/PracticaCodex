# Estructura del Repositorio (Plantilla para estudiante)

## 1. Árbol propuesto

```text
nombre-del-proyecto/
├── README.md
├── docs/
│   ├── propuesta.md
│   ├── caso_de_uso.md
│   ├── estructura_repositorio.md
│   └── plan_de_pruebas.md
├── src/
│   └── main.<ext>
├── scripts/
│   └── run.sh
└── tests/
    └── test_plan.md
```

## 2. Función de cada carpeta/archivo
- `docs/`: documentación principal del diseño.
- `src/`: código fuente mínimo (opcional para prototipo).
- `scripts/`: automatización básica de ejecución.
- `tests/`: plan y evidencias de pruebas.

## 3. Convenciones de nombres
- Archivos en minúsculas y con guion bajo.
- Scripts ejecutables con nombres cortos (`run.sh`).
- Commits pequeños y descriptivos.

## 4. Estrategia de versionamiento
Describe cómo separarás tus commits por etapas:
1. Documentación base
2. Ajustes de alcance
3. Plan de pruebas
4. Prototipo mínimo (opcional)
