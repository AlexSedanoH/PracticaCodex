# Plantilla de Propuesta: Práctica Temática Pequeña

Este repositorio está listo para publicarse en GitHub Classroom como actividad de diseño y documentación.

## Objetivo
Que el estudiante proponga un proyecto pequeño y realista, con prioridad en:
- documentación técnica,
- planeación,
- estructura del repositorio,
- y justificación del caso de uso.

## Lenguajes permitidos (elige uno)
- ARM64 Assembly
- C
- Python
- Bash

> ARM64 Assembly se recomienda solo para programas muy pequeños y acotados.

## Estructura mínima incluida
- `README.md`
- `docs/propuesta.md`
- `docs/caso_de_uso.md`
- `docs/estructura_repositorio.md`
- `docs/plan_de_pruebas.md`

## Estructura opcional incluida como base
- `src/main.ext`
- `scripts/run.sh`
- `tests/test_plan.md`

## Instrucción para el estudiante
Completa los archivos en `docs/` siguiendo los apartados de cada plantilla.
